# HeyBox Community Refined

一个 Edge/Chromium Manifest V3 扩展，为小黑盒 BBS 的已确认桌面路由提供可撤销的双栏阅读布局增强。

## v0.5.3 范围

- 统一社区首页与帖子详情的圆角、边框、背景和轻阴影变量：面板 12px、帖子卡片 10px、输入/按钮 8px、小型控件 6px。
- 移除首页信息流外层冗余白色背景，保留原站 16px 横向安全间距，让独立帖子卡片直接呈现在浅灰页面底色上。
- 搜索框、Dock、热门社区、相关推荐、评论引用与回复输入框均复用同一套视觉令牌；不改变三栏布局、媒体轮播或原生交互。

## v0.5.2 范围

- 首页刷新控件从信息流顶部工具行移至视口右下角的 44×44px 悬浮图标按钮；保留原刷新逻辑、设置开关与 SPA 清理，并对原站右下角固定控件进行动态向上避让。
- 首页三栏改为同一网格行，Dock、第一张帖子卡片和右栏从同一水平位置开始；删除旧工具行节点、样式与其占用的独立网格行。

## v0.5.1 范围

- v0.5.1 修复原站 `#app > main { max-width: 1300px }` 继续限制页面宽度的问题；宽屏首页可用布局扩展至约 1500px，详情页上限为 1320px。
- Dock 原生按钮明确使用横向 Flex，图标在左、文字在右；布局尺寸与 Edge 对照截图见 `docs/V051_LAYOUT_REPAIR.md`。

- v0.5 统一首页与详情页的桌面布局上限为 1520px，解除首页信息流的残留最大宽度；搜索栏、信息流工具栏和右侧推荐栏沿同一网格对齐。
- 社区 Dock 继续复用原生 Vue 按钮及切换逻辑，并收紧为图标在左、文字在右的可滚动列表；折叠、刷新、顶栏精简和推广隐藏设置均保留。
- 仅收紧帖子卡片、详情正文和评论的外层间距。详情页 Swiper 仍不改写容器/slide/图片尺寸、`transform` 或 `object-fit`，以保护竖图、横图、多图和灯箱交互。

- 只匹配 `https://xiaoheihe.cn/app/bbs/*`，运行时只启用：首页 `/app/bbs/home`、数字帖子详情 `/app/bbs/link/<数字 ID>`。
- Popup 提供总开关、首页开关和详情开关；设置仅保存在 `chrome.storage.local`。
- 宽度大于 1080px 时使用信息流与热门讨论的稳定双栏，容器上限 1200px、右栏 310px；保留原生社区分类条的水平滚动和分页行为。小于等于 1080px 不施加布局覆盖。
- v0.2 统一首页和详情页的卡片、文字、边框和评论阅读层级；详情头图只约束外层最大宽度，不裁切、不改写图库内部尺寸。
- v0.3 默认精简社区顶栏，并隐藏 APP 下载二维码及产品快捷入口；热门社区、相关推荐、备案、举报和版权信息仍保留。Popup 可分别关闭「精简社区顶栏」与「隐藏产品推广」。
- v0.4 在桌面首页将原生社区分类重排为可折叠左侧 Dock，保留其原生按钮与切换逻辑；新增首页刷新按钮。低于 840px 恢复原横向分类条。
- 不插入、克隆、替换或拦截任何小黑盒交互节点。关闭任一开关即移除 `html` 上的扩展状态 class，恢复原站样式。

## 项目结构

```text
src/             扩展入口、路由适配、设置、功能状态与作用域 CSS
public/          本地扩展图标等静态资源
scripts/         离线 DOM 选择器审计工具
tests/fixtures/  脱敏 DOM 样本与选择器快照
docs/            设计、DOM 证据、验收与风险文档
```

## 本地开发与构建

```powershell
npm install
npm run typecheck
npm run build
```

构建后，Chromium 产物在 `.output/chrome-mv3/`。在 Edge 打开 `edge://extensions`，启用「开发人员模式」，点击「加载解压缩的扩展」，并选择该目录。

`npm run zip` 会额外生成适合手动分发的压缩包。扩展不声明网络、Cookie、后台代理、遥测或动态脚本权限。

## 实现边界

样式仅作用于 `html.hcr-enabled.hcr-home #page-bbs-community` 或 `html.hcr-enabled.hcr-post #page-bbs-link`。首页不修改搜索框、分类条的溢出规则、固定遮罩或图集内部绝对定位；详情页不修改回复栏及其祖先的 sticky/overflow/transform 属性。

离线 DOM 证据位于 `docs/` 与 `tests/fixtures/`。这些快照不是线上兼容性的保证；发布前需按 `docs/05_ACCEPTANCE_TESTS.md` 在 Edge 逐项完成实测。

# 00 · 项目范围与证据说明

## 项目定位
“网页增强插件”，不是“小黑盒第三方客户端”。保留原站身份认证、内容加载、所有按钮和交互。增强作用于浏览器当前页面的布局、可读性和操作密度。

## 需求排序
- P0：首页与详情页可选开启/关闭；已确认社区路由识别；宽屏利用率；无交互回归；刷新和 SPA 切换生效。
- P1：卡片元信息、摘要、标题、间距、侧栏与评论阅读优化；UI 细节统一。
- P2：紧凑模式、主题、用户可设字号/最大宽度、无障碍增强。
- P3：可折叠社区导航、键盘快捷键等易导致 DOM/行为变化的功能，单独提案和实测。

## 证据等级
- **已从离线 HTML 验证**：DOM 层级、选择器、该快照节点数量、静态样式文件中的 CSS 规则、首页帖子 href 示例路径。
- **设计建议**：宽屏 1280~1400px 容器、右栏 300~320px、正文最大阅读宽度 760~820px、卡片视觉参数。
- **尚未验证**：站点当前线上是否与快照一致、网页执行 SPA 切换细节、所有类型帖子的结构、深色模式、浏览器实测交互效果。

## 已发现的原站重要约束
首页页面根为 `#page-bbs-community`，详情页根为 `#page-bbs-link`；两类页面的顶层 DOM 与滚动结构不同，所以应该分别使用作用域 CSS。首页搜索区 sticky top:80px；首页右侧栏 sticky top:138px；详情右侧栏 sticky top:80px；详情评论输入条位于底部 sticky。页面宽度调整可能破坏伪元素遮罩/吸附和内联定位图集；必须单独测试。

## 敏感资料处理
不放入未经匿名化的原始 HTML、图片和保存网页资源；不将已登录用户信息、个人主页链接、具体帖子 ID 作为测试夹具。去标识化骨架不是可运行网页，不能代替浏览器实测。

# v0.5.2 悬浮刷新与三栏顶部对齐

## 审计结论

- 旧实现把 `[data-hcr-feed-toolbar]` 放在中央信息流上方，并为首页网格定义了 `auto minmax(0, 1fr)` 两行。
- 左侧 Dock 与右栏跨两行，中央信息流固定在第二行，因此第一张帖子必然比左右栏低一个工具行高度及行间距。
- 仅删除刷新按钮不足以修复错位，因为空工具行与网格第一行仍会继续占位。

## 修改

- 删除旧工具行的创建与样式，并在每次状态同步时清理 SPA 文档中可能残留的旧节点。
- 首页三栏容器改为单行网格；Dock、信息流和右栏统一放在第一行，保留原有列宽与 gap。
- 新增 `data-hcr-floating-refresh` 按钮，直接挂到 `body`，仅首页启用；沿用 `showFeedRefresh` 设置及 `location.reload()` 刷新逻辑。
- 按钮默认 44×44px、right 24px、bottom 28px；窄窗口为 40×40px、right 14px、bottom 18px。
- 采样视口右下区域的原站固定控件，检测到可见控件时把按钮上移 12px 间距。SPA 路由变化、设置关闭及页面卸载时移除扩展节点。
- 中央信息流外层使用与左右栏相同的 10px 圆角；保留 `overflow: visible`，避免裁切原站浮层或改变交互。

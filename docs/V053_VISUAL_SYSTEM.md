# v0.5.3 圆角与卡片视觉系统

## 审计结论

实际 Edge computed style 显示，首页白色长条来自原站 `.bbs-home__content-list`：它保有白色背景和 `padding: 0 16px`。此前插件只给该容器添加 10px 圆角，但其白底仍覆盖整个信息流列，因此帖子自身的圆角无法形成独立卡片层级。

同时，原覆盖规则中搜索输入为 8px、Dock/帖子/热门社区均为 10px、社区项为 7px，面板与卡片没有明确层级。阴影也混用了两个不同强度的硬编码值。

## 统一令牌

| 层级 | 令牌 | 值 |
|---|---|---:|
| 面板 | `--hcr-radius-panel` | 12px |
| 帖子卡片 | `--hcr-radius-card` | 10px |
| 输入与按钮 | `--hcr-radius-control` | 8px |
| 小型控件 | `--hcr-radius-small` | 6px |

边框收敛为 `--hcr-border-color: #e6e9ed`，页面底色为 `--hcr-page-bg: #f6f7f9`，卡片阴影为 `--hcr-shadow-card: 0 1px 3px rgb(20 25 35 / 3.5%)`。

## 实施

- 信息流外层保留原站 16px 横向安全间距，但变为透明、无边框、无阴影、无圆角；每张 `.hb-cpt__bbs-list-content` 独立承担白底、边框、10px 圆角与轻阴影。
- 搜索输入、Dock、热门社区、帖子详情外层与相关推荐采用 12px 面板圆角。
- 评论引用框和回复输入框采用 8px；Dock 内部社区项采用 6px；头像和悬浮刷新按钮的圆形规则未改动。
- 未给帖子整体设置 `overflow: hidden`，未修改 Swiper 内部尺寸、定位、`transform` 或溢出规则。

## 1570×904 Edge 实测

| 元素 | 圆角 | 背景 | 边框 |
|---|---:|---|---|
| 搜索输入 | 12px | 白色 | `#e6e9ed` |
| Dock / 热门社区 | 12px | 白色 | `#e6e9ed` |
| 信息流外层 | 0px | 透明 | 无 |
| 首页帖子卡片 | 10px | 白色 | `#e6e9ed` |
| 详情主卡片 / 相关推荐 | 12px | 白色 | `#e6e9ed` |
| 评论引用 / 回复输入 | 8px | 页面底色 / 白色 | `#e6e9ed` |

首页、详情截图使用同一 1570×904 CSS viewport、DPR 1。两页均无水平溢出；首页三栏依旧从 y=138px 对齐。
首页实际命中的 10 张帖子卡片均返回相同的 10px、白色背景与 `#e6e9ed` 边框计算值。

## 待人工验证

- 登录状态下的个人菜单、帖子操作菜单和图片灯箱不被原站自身临时背景覆盖。
- Dock 滚动、折叠、原生社区切换、评论输入和发布均保持原站交互。
- 关闭总开关或页面开关后，所有 `hcr-*` 样式和扩展插入节点恢复原站状态。

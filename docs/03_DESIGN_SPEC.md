# 03 · UI / UX 设计规范（开发基线）

## 产品原则
以 Reddit 的信息组织、V2EX 的简洁阅读密度、Discourse 的讨论层级为**设计理念参考**，而不是复制任何站点布局与品牌。不引入不必要的玻璃拟态、大圆角胶囊、全屏动画。保留小黑盒现有图标、配色语义与交互。

## 页面优先级
- 首页：搜索栏 → 社区分类 → 主信息流标题/摘要/图片/互动 → 右栏热点社区。
- 详情：返回/作者 → 封面 → 正文标题/阅读 → 评论及回复 → 右侧相关推荐。
- 宽屏（大于 1080px）使用原生分类条、主信息流和右侧热门讨论组成的双栏页面；不得创建、克隆、替换或纵向重排分类按钮，必须保留其原始水平滚动、点击与分页行为。1080px 及以下尊重原站布局。

## 响应式候选设计（待现场调参）

| 视口宽度 | 候选布局 | 验收重点 |
|---|---|---|
| `<1080px` | 优先原站单列行为 | 没有横向滚动、按钮不被遮挡 |
| `1080–1199px` | 尽量原站布局 | 页面仍可用，不抢原断点 |
| `1200–1439px` | 双栏、适度扩展容器 | 右栏不挤压帖子/正文 |
| `1440–1719px` | 双栏容器上限 1200px | 主栏内容宽度合理 |
| `≥1720px` | 双栏容器仍为 1200px 上限 | 不因宽屏而导致正文过长 |

候选 token：

```css
/* 仅设计基线；实际由 Codex 在有作用域的页面 CSS 中实现 */
:root {
  --hcr-layout-max: 1200px;
  --hcr-side-width: 310px;
  --hcr-layout-gap: 22px;
  --hcr-readable-max: 760px;
  --hcr-card-radius: 10px;
  --hcr-border-color: #e8eaed;
  --hcr-secondary-text: #6c727a;
}
```

## 首页
- 主栏须解决原生 `max-width:660px`，否则扩宽主容器无效。
- 帖子间距与分隔：明确边界，避免过大空白；用户头像、等级和操作按钮保留原尺寸体系，只调整微间距。
- 标题与正文：保证中文断行正常、emoji 与富文本图标不被改变 display/size；摘要保持合理 clamp。
- 配图：保留现有 `position:relative` 容器 + `position:absolute` 图片排列，第一版**不重排**；图片大小不应超过卡片，若由于宽度变化显示错误，优先回退该项。
- 顶部分类：保留水平滚动或分页组件；不将可点击 button 强改为其它节点。
- 搜索栏：原为 sticky top:80px；避免新定位或父级 overflow 导致 sticky 失效；保留焦点态和下拉联想菜单的层级。
- 右侧社区：宽度约 300~320px 只是建议，实际验证 `hot-topic__look` 按钮宽度、二维码和 app-links 的布局。

## 帖子详情
- 标题适当增加对比度，作者与时间信息应易于区分。
- 内容只在外围限制排版宽度，不可让媒体、代码块、图片、互动浮层溢出。
- 评论阅读强调作者/正文/回复层级，不修改原生评论节点或 56px 缩进机制。
- 原生回复栏必须能输入、失焦、发送与弹出表情，且页面底部固定的空间不会遮挡评论末尾。

## 页面视觉
- v0.1 默认保留原站浅色视觉，不用全局滤镜变暗；设置中的深色主题为将来单独迭代。
- 以小圆角、轻边框、少量背景色层次提升可读性，避免全局 `*` 选择器和大量 `!important`。
- 保留文字对比度与 focus 可见性；不移除原站 hover/active 状态。
- 推荐正文中文字号约 15~16px、行高 1.55~1.7，最终以原站实际字体呈现为准。

## 行为约束
- 插件关闭后 100% 不保留新布局类、style 标签、监听器、插入节点。
- SPA 切换到未知 `/app/bbs/*` 路由不显示旧页面的布局状态。
- 通过选择器未匹配导致的情况应安全失败而非强行插入假节点。

## 自动检查
- [ ] `npm install` 或项目锁文件对应安装命令成功
- [ ] TypeScript 类型检查成功

- [ ] 没有站点 API 拦截、遥测、远程动态脚本、敏感权限

- [ ] `tests/fixtures/selectors.json` 所列快照选择器可被离线验证（可选）

## Edge 人工检查（每项需填写：通过 / 失败 / 未执行）

| 组 | 用例 | 期望 |
|---|---|---|
| 启用/禁用 | 首页总开关多次切换 | 立即变化，恢复原站，无重复节点 |
| 启用/禁用 | 详情页总开关多次切换 | 不破坏输入条/布局，关闭恢复 |
| 设置 | 单独关闭首页/详情 | 分页面开关互不影响 |
| 刷新 | 开启状态 F5、硬刷新 | 配置保持，避免样式闪烁 |
| 路由 | 首页打开帖子、返回 | 两页正确应用/清理样式 |
| 路由 | 打开其它小黑盒页面 | 不注入非社区样式 |
| 首页 | 搜索输入、回车、建议下拉 | 聚焦和下拉位置正确，不被遮罩 |
| 首页 | 社区分类滚动/翻页/点击 | 可见、可点击、跳转正常 |
| 首页 | 点击标题、图片、作者头像 | 导航/灯箱行为原样 |
| 首页 | 点赞、更多菜单、评论入口 | 没有错位或不可点击 |
| 首页 | 多图/长标题/emoji 卡片 | 不重叠、不裁切 |
| 首页 | 滚动加载更多 | 无重复注入/无页面抖动 |
| 详情 | 返回/关注/分享/举报 | 原生功能可用 |
| 详情 | 正文图片/轮播/长图 | 不溢出，查看操作正常 |
| 详情 | 评论/楼中楼展开收起 | 交互与层级保留 |
| 详情 | 底部评论输入、焦点/表情/回复 | sticky 正常，无按钮遮挡 |
| 详情 | 页面滑动、侧栏滚动 | sticky 和内部滚动正常 |
| 通用 | 1200、1280、1440、1720 px | 无横向溢出，间距合理 |
| 通用 | 1080、1000、768 px | 不强制显示右栏，保留原生布局 |
| 通用 | 100%、125%、150% 缩放 | 文字、按钮、浮层不会严重重叠 |
| 通用 | 登录/未登录、不同帖子类型 | 安全失败或正确工作 |
